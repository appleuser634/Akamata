# Security Policy

## Supported versions

Security fixes are provided on the current `main` branch. Until Akamata publishes stable release lines, older commits and generated vendored copies are not supported.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Use GitHub's private vulnerability reporting for `appleuser634/Akamata`. Include affected revisions, reproduction steps, impact, and any suggested mitigation. Do not include production secrets, personal data, or live credentials.

We will acknowledge a complete report, investigate it, coordinate a fix, and publish details after users have a reasonable opportunity to update.

For deployment guidance and framework boundaries, see [English](docs/en/security.md) or [日本語](docs/ja/security.md).
