# Akamata v0.1.2

Akamata v0.1.2 adds safe project upgrades for both Zig dependencies and
generated Cloudflare Workers runtime files.

Highlights:

- `akamata update [--to=vX.Y.Z] [--sync] [--dry-run]` updates only the Akamata
  dependency URL/hash and validates Native and Workers builds.
- `akamata sync [--dry-run] [--force]` synchronizes the Workers HTTP bridge,
  JSPI dispatch serializer, internal-route guard, and realtime Durable Object
  adapter.
- `.akamata/managed-files.json` records SHA-256 generation hashes and cleanly
  separates framework-managed files from user-owned source and Wrangler config.
- Local managed-file edits are refused atomically by default. Forced updates
  preserve `.bak` copies.
- Unmodified pre-manifest v0.1.0 Workers projects are recognized and upgraded,
  including propagation of the v0.1.1 WASM dispatch serialization fix.
- CI now builds both fresh scaffolds and upgraded legacy projects for Native
  and Workers targets.

Recommended upgrade:

```bash
akamata update --to=v0.1.2 --sync --dry-run
akamata update --to=v0.1.2 --sync
git diff
```

For details, see [CHANGELOG.md](../../CHANGELOG.md) and the
[upgrade guide](../en/upgrading.md).
