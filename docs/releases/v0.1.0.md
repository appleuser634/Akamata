# Akamata v0.1.0

Akamata v0.1.0 evolves the project from a runtime-focused Zig web framework
into a compile-time oriented portable backend and realtime framework while
preserving the existing `App(State)`, `Context(State)`, middleware, database,
OpenAPI, client-generation, and Workers APIs.

Highlights:

- Compile-time route graphs, typed inputs, typed error maps, capability checks,
  static middleware, DB specialization, and DI validation.
- Typed versioned events and portable realtime behavior across Native
  WebSockets and Cloudflare Durable Objects.
- Filesystem and R2 object storage with metadata, ETags, Range requests,
  conditional access, bounded listing, and streaming-oriented contracts.
- TypeScript realtime and bounded C/embedded protocol generation.
- A contract-aware CLI client/TUI plus route inspection, API diffing, resource
  generation, database sandboxing, and project diagnostics.
- A portable reference application and expanded compile-fail, parity,
  integration, benchmark, and optional live Cloudflare coverage.

Compatibility and trade-offs:

- Existing runtime APIs remain supported; the comptime and portable APIs are
  additive.
- Zig 0.16.x is required.
- The current Workers HTTP/WASM bridge still bounds and buffers request bodies;
  R2 uploads are limited to 8 MiB by the bridge and are not zero-copy.
- R2 `head` currently exposes size only; use `get` when conditional metadata is
  required.

For the detailed change list, see [CHANGELOG.md](../../CHANGELOG.md). Architecture
and platform constraints are documented in the
[compile-time](../en/comptime-architecture.md) and
[portable backend](../en/portable-backend.md) guides.
