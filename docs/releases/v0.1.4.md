# Akamata v0.1.4

Akamata v0.1.4 hardens the portable building blocks introduced in v0.1.3.

Highlights:

- `am.crypto.randomHex` now works with runtime lengths on native and Workers.
- Byte arrays and slices preserve their complete value across SQLite and D1;
  unsupported bind types fail at compile time instead of silently corrupting
  data.
- CSRF middleware supports dynamic Host-aware origin policy and application-
  owned session verification hooks while retaining safe defaults.
- English and Japanese guidance now distinguishes Repo, Query, preload,
  DTO-mapped raw SQL, and explicit complex business SQL.

Existing public APIs remain compatible. The new CSRF hooks are opt-in.

Recommended upgrade:

```bash
akamata update --to=v0.1.4 --sync --dry-run
akamata update --to=v0.1.4 --sync
git diff
```
