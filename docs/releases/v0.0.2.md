# Akamata v0.0.2

This release focuses on correctness, security, lifecycle ownership, and explicit
failure modes across Akamata's native and Workers targets.

## Highlights

- Route registration is frozen after preparation and ambiguous routes are rejected.
- Forwarded client IP headers now require an explicit trusted-proxy policy.
- Session and rate-limit state is isolated per App and released on teardown.
- Outbound HTTP framing and header validation reject injection and truncation.
- SQLite/Turso transactions, bounded database pools, and recoverable job leases were added.
- OpenAPI and TypeScript generation now preserve more of the endpoint contract.
- The experimental reactor and unfinished Zig client target fail closed instead of
  exposing incomplete production behavior.
